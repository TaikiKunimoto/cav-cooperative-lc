## 用語

| 用語 | 意味 |
|---|---|
| 操作（`LCOperation`） | 車が済ませるべき車線変更 1 つ。目標レーン `target_lane` と締切位置 `deadline_pos`（D） |
| 要求車 | 活性化窓の中にいて，アクティブな操作が未完了の車 |
| 提供車 | 要求車のために後ろで減速してすき間を開ける役に割り当てられた車 |
| 本線 edge | 環境ごとの調停区間（`Environment.mainlane_edge`）。縦位置 `lane_pos` はこの edge の始端から測る |
| 実効距離 dist | `(D − pos) − (k − 1)·R`。k は残りの車線変更の段数 |
| レーン番号 | 0 が右端（最下段）。`CarAction.CHANGE_LEFT` は番号が増える向き |

## 挙動が変わっていないかの確かめ方

v2 のリファクタでは，`uv run python tests/golden/run_golden.py check --suite v2` が差分ゼロになることを確かめる（`tests/golden/README.md`）。
