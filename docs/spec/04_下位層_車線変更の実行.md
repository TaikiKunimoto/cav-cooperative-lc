# 04 下位層：車線変更の実行（`Layer2.execute_pairs`）

毎 step，直近の Tc の要求を鍵順に処理する。

```
committed = {}                               ← この step で入ることが決まった (目標レーン → 縦位置)
1. 挿入を試す（鍵順）
   next = 今のレーン ± 1
   if _insertion_safe_live(要求車) and _slot_free(committed, next, pos):
       changeLane(要求車, next, 0)；committed[next] に pos を足す
   else:
       unresolved に回す
2. unresolved の中で対向スワップ（_execute_swaps）
3. スワップしなかった unresolved の各要求車:
   - 割当の提供車がいれば _provider_yield（提供車の速度）
   - dist ≤ HOLD_MARGIN（100 m）なら _hold_before_deadline，そうでなければ _requester_align_to_slot（要求車の速度）
```

`changeLane(id, lane, 0)` は次の step に反映される 1 段の瞬時の車線変更。挿入の判定は提供車の有無に関係なく行う。

## 挿入の安全判定（`_insertion_safe_live`）

目標レーンの後続と先行を `getNeighbors` で取る（ジャンクションをまたぐので，本線 edge の外から入ってくる車も見える）。`getNeighbors` の距離 `dist` は minGap を差し引いた値（バンパー間 − minGap。重なっていれば負）として扱う。

- 後続のそれぞれ: `dist ≥ _net_required(v_後続, v_自車)`
- 先行のそれぞれ: `dist ≥ _net_required(v_自車, v_先行)`

```
_net_required(v_back, v_front) = max(0, (v_back² − v_front²) / (2 × 5.0))   ← 相対制動
                                 + v_back × LC_REACTION_LAG (0.25 s)          ← 追従の追跡遅れ
                                 + LC_SAFETY_MARGIN (0.5 m)                   ← 判定と反映の 1 step のずれ
```

## 同じ step のスロット（`_slot_free`）

同じ step に同じ目標レーンへ入る車どうしで，縦位置の差が `VEH_LENGTH + MIN_GAP`（7.8 m）未満なら，後から来た方を入れない。

## 対向スワップ（`_execute_swaps`）

`unresolved` を鍵順に見て，次をすべて満たすペア (a, b) を同じ step で入れ替える（両方に `changeLane`）。1 台は 1 回だけ入れ替える。

1. b が a の次の目標レーンにいて，b の次の目標が a の今のレーン
2. 縦位置の差が `SWAP_WINDOW`（7.8 m）以内
3. 入れ替え先のスロットが両方とも空いている（`_slot_free` を 2 つ）
4. スナップショットでの検査（`_swap_gap_ok`）: 相手を除いた目標レーンの最も近い先行・後続に対し，バンパー間の距離（前端の位置 − 車長）が `_net_required` 以上
5. 実測での検査（`_swap_live_gap_ok`）: 相手を除いた `getNeighbors` の先行・後続に対し，`dist ≥ _net_required`。ただし**壁ペア**（両者とも `pos ≥ D − SWAP_WINDOW`）で，自車とその近くの車の速度がともに `SWAP_STOPPED_EPS`（0.5 m/s）未満なら，要求量から `MIN_GAP` を引く

入れ替えたら `[swap]` をログに出す。

## 提供車の譲歩（`_provider_yield`）

```
gap      = 要求車の lane_pos − 提供車の lane_pos         （前端どうしの距離）
Δv       = v_提供 − v_要求
required = VEH_LENGTH + 1.5 × MIN_GAP (= 9.2 m)  [+ G_req(v_提供) × Δv / MAX_SPEED  ← Δv > 0 のとき]
```

| 条件 | 提供車の目標速度 |
|---|---|
| gap < required で，要求車が 1 m/s 未満か gap < 車長 | 前方に `pass_room` = gap + 車長 + MIN_GAP + 2 m 以上の余地があれば `v_要求 + ALIGN_DELTA`（追い越して後ろを空ける）。無ければ 0（その場で止まる：courtesy hold） |
| gap < required（上以外） | `v_要求 × (1 − 0.7 × min(不足 / required, 1))`（不足に比例して下がる） |
| gap > 2 × required | `v_要求 + min(余剰 / 5, √(5 × max(余剰 − 3, 0)))`，余剰 = gap − 2 × required（詰める） |
| それ以外 | `v_要求`（同じ速度で保つ） |

目標速度は提供車のレーンの制限速度で頭打ちにする。減速は最大減速度（5.0 m/s²）で行う。加速は，前方に `safety_gap + 車長` 以上の余地があるときだけ `MAX_ACCEL` で行う。

## 締切前の hold（`_hold_before_deadline`）

dist ≤ `HOLD_MARGIN` で，まだ入れない要求車の速度。

- 速度が 0 以下，または前方車が `safety_gap` より近ければ何もしない（`control_speed` に任せる）。
- 締切 D までの残り距離で止まれる減速度（上限 5.0 m/s²）で，`slowDown(0)` を出す。

## スロット整列（`_requester_align_to_slot`）

dist > `HOLD_MARGIN` で，まだ入れない要求車の速度。速度が 0 以下，または前方車が `safety_gap` より近ければ何もしない。目標レーンの先行・後続を `getNeighbors` で見て，上から順に判定する。

1. 先行に**対向要求車**（次の目標が自分の今のレーン）がいて `dist < _net_required` → その車の速度 − `ALIGN_DELTA`（2 m/s）まで減速する（後ろへずれる）
2. 後続に対向要求車がいて `dist < _net_required` → `ALIGN_DELTA` だけ増速する（制限速度と，先行の速度 + `ALIGN_DELTA` で頭打ち。前へずれる）
3. どちらでもない → 目標レーンの先行の最も遅い速度まで減速する（先行がいないか，すでに遅ければ何もしない）
