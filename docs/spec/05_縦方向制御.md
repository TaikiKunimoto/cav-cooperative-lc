# 05 縦方向制御（`V2CAV.control_speed`）

毎 step，走行中の全車について上から順に判定し，最初に当てはまったところで指令を出して終える。その後 `Layer2` が上書きしうる（01）。

先行車は `getLeader(id, 0)` で取る。距離 `leader_distance` は `getLeader` が返す値（07 の要確認 1・2）。

| # | 条件 | 指令 |
|---|---|---|
| 1 | 障害物 | `setSpeed(0)` |
| 2 | `leader_distance < MIN_GAP` | 緊急減速：`setSpeed(min(v_先行, v_自車, 1.0))` |
| 3 | 臨界制動バンド：`v_自車 > v_先行` かつ `leader_distance < (v_自車² − v_先行²) / (2 × 5.0) + 1.0 + 0.2 × v_自車` | `slowDown(v_先行, Δv / 5.0)`（最大減速で先行の速度に合わせる） |
| — | （ここで `do_not_speed_up` = status が `YIELDING` か `LANE_CHANGING`） | — |
| 4 | 先行車なし | 制限速度へ（下の「制限速度へ」） |
| 5 | `leader_distance ≥ safety_gap` で，Δv ≤ 0 か「最大減速で速度差を消す時間 < TTC」 | 制限速度へ |
| 6 | `leader_distance ≥ safety_gap`（5 以外） | `slowDown(v_先行, min(TTC, Δv / 5.0))` |
| 7 | `leader_distance < safety_gap` で `do_not_speed_up` | 何もしない |
| 8 | `leader_distance < safety_gap` で Δv ≥ 0 | `slowDown(max(v_先行 − 1, 0), min(TTC, Δv / 5.0))`（先行が 1 m/s 以下なら目標 0） |
| 9 | `leader_distance < safety_gap` で Δv < 0 | 何もしない |

- Δv = v_自車 − v_先行，TTC = `leader_distance / Δv`（Δv ≤ 0 なら無限大）。
- **制限速度へ**：制限速度を超えていれば最大減速度で下げる。下回っていれば，`do_not_speed_up` でない限り `MAX_ACCEL`（2.6 m/s²）で上げる。
- `safety_gap` = `Safety.g_req(v_自車)` = `v × δ + (3.6 v)² / (254.016 × 0.7) + MIN_GAP`（δ = `DELAY` = 0）。観測（`update_self_observation`）のたびに計算し直す。
- 「何もしない」ときは，前の step までに出した `slowDown` が残っていればそれが続く（07 の要確認 4）。

## 補足

- 加速の上限：`speedMode 0` では vType の `accel` が指令に効かないので，`slowDown` の継続時間を `Δv / MAX_ACCEL` にして 2.6 m/s² を実効の上限にしている。
- `utils/traci_wrapper.slow_down` は，速度と継続時間の異常値（負・NaN・無限大・上限超え）を丸めてから `slowDown` を呼ぶ。
- `leader_distance` は，`hold`・スロット整列・提供車の加速可否の判定（04）と，TTC の統計（06）にも使われる。
