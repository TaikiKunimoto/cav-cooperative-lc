# 06 計測

## 操作の完了（`V2CAV.update_deadline_achievement`，毎 step）

本線 edge の上にいるときだけ判定する。まだ `completed_in_time` でない操作について：

- 回避操作：`is_done`（障害物を通過した）なら `completed_in_time = True`
- 通常の操作：今のレーンが目標で，かつ `lane_pos ≤ deadline_pos` なら `completed_in_time = True` とし，そのときの時刻と位置を `completion_time`・`completion_pos` に残す

一度立てた `completed_in_time` は戻らない。

## 締切達成の集計（`V2CAV.record_deadline_outcome`）

車が出ていったとき（`accumulate_exit_stats` から）と，終了時に走行中だった車について，1 台 1 回だけ呼ばれる。

- 通常の操作と回避操作を別に数える（`record_deadline_achievement`・`record_avoidance_achievement`）。
- 要求数 = 活性化した操作の数，完了数 = そのうち `completed_in_time` の数，未完了 = 要求数 − 完了数。
- 衝突に一度でも関わった車は，その車の要求数をそのまま「衝突」として別に数える（完了数からは引かない）。
- 活性化しなかった操作は数えない。

## 個票の CSV

出力先と名前は `SimulationStatistics` が決める（`EVAL_OUTPUT_DIR`・`EVAL_OUTPUT_NAME` で上書きできる）。

| ファイル | 中身 |
|---|---|
| `<名前>.csv` | run ごとの結果 1 行（締切達成・衝突・速度・TTC など） |
| `<名前>__requests.csv` | 活性化した通常の操作すべて（完了したものを含む）。列は `V2CAV.MANDATORY_REQUEST_FIELDS`。回避操作は含まない。行が無くても見出し行は書く |
| `<名前>__failures.csv` | 活性化した操作のうち，未完了のもの，または衝突に関わった車のもの。回避操作も含む。分類は `COLLIDED`（衝突に関与）→ `TIMEOUT_STUCK`（終了時に走行中）→ `EXITED_INCOMPLETE`（未完了のまま退出）の順に当てる。該当が無ければファイルを作らない |

## そのほか

- 衝突：`_check_collision` が毎 step `getCollidingVehiclesIDList` を見て記録する。同じ組が 1 s 以内に続けて出たら 1 件にまとめる。
- TTC：走行中の各車の `leader_distance`・先行の速度・自車の速度から `stats.calculate_TTC` で計算する。
- 走行時間と平均速度：退出した車について計算する。終了時に走行中だった車は平均速度だけ計算する。
- `traffic_volume` = 発進した台数 × 3600 / T（ドレーンの時間は含めない）。
- `canceled`：流入時刻になっても発進できなかった車（衝突に関わった車は除く）。
- 終了時の表示：鍵の同点と提供車の二重割当が起きた Tc の回数，`Layer2` の車線変更の総数，締切達成（通常・回避），衝突の一覧。
