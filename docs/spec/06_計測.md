# 06 計測

計測はポリシー（01）によらず同じに動く。調停と速度に関わる数（鍵の同点・二重割当・規則の数え上げ・緊急制動・任意の車線変更・速度ログ）は，`off`・`off-late` では 0 か空になる。

## 操作の完了（`V2CAV.update_deadline_achievement`，毎 step）

本線 edge の上にいるときだけ判定する（本線の外のレーン番号は別の edge のもので，目標レーンと比べられない）。まだ `completed_in_time` でなく，回避後に戻る操作（`is_return`）でもない操作について：

- 回避操作（`is_avoidance`）：`is_done`（縦位置が締切＝障害物の位置以上。障害物を通過した）なら `completed_in_time = True`。完了の時刻と位置は残さない。
- 通常の操作：`reached_target_in_time`（今のレーンが目標で，かつ `lane_pos ≤ deadline_pos`）なら `completed_in_time = True` とし，そのときの時刻と位置を `completion_time`・`completion_pos` に残す。

一度立てた `completed_in_time` は戻らない。ここでは活性化したかを見ない（集計で数えるのは活性化した操作だけ）。回避後に戻る操作は完了を判定せず，以下の集計と個票のどれにも入らない（ドレーンを続ける条件には入る。01）。

## 締切達成の集計（`V2CAV.record_deadline_outcome`）

車が出ていったとき（`accumulate_exit_stats` から）と，終了時に走行中だった車について，1 台 1 回だけ呼ばれる。

- 通常の操作と回避操作を別に数える（`SimulationStatistics.record_deadline_achievement`・`record_avoidance_achievement`）。
- 要求数 = 活性化した操作の数，完了数 = そのうち `completed_in_time` の数，未完了 = 要求数 − 完了数。
- 衝突に一度でも関わった車（`collided_ids`）は，その車の要求数をそのまま「衝突」として別に数える（完了数からは引かない）。
- 活性化しなかった操作と，回避後に戻る操作は数えない。
- `SimulationStatistics` は「要求数 = 完了数 + 未完了」と「衝突 ≤ 要求数」を確かめ，成り立たなければ `ValueError` を投げる。
- 達成率 = 完了数 / 要求数（要求が無ければ空）。

## 出力ファイル

出力先は `simulationStatistics/statistics/v2`（`TraCI/` からの相対。`simulation.OUTPUT_DIR`）で，環境変数 `EVAL_OUTPUT_DIR` があればそちらにする。ファイル名は `<出力名>_<YYYYmmdd_HHMM>.csv`（同じ名前が既にあれば `-2`，`-3`，… を足す）で，環境変数 `EVAL_OUTPUT_NAME` があれば `<EVAL_OUTPUT_NAME>.csv` にする（出力名は 01）。以下，拡張子を除いた部分を `<名前>` と書く。追加のファイルは `SimulationStatistics.write_sidecar` などが `<名前>` に接尾辞を付けて書く。

| ファイル | 書く条件 | 中身 |
|---|---|---|
| `<名前>.csv` | 常に（見出し行は開始時に書く） | run ごとの結果 1 行 |
| `<名前>__requests.csv` | 常に（行が無くても見出し行を書く） | 活性化した通常の操作すべて（完了したものを含む）。回避操作と戻る操作は含まない |
| `<名前>__failures.csv` | 該当があるときだけ | 活性化した操作（回避操作を含み，戻る操作は除く）のうち，未完了のもの，または衝突に関わった車のもの |
| `<名前>__discretionary.csv` | `edf`・`none` のとき（`DISCRETIONARY_LC` が 0 でも書く） | 任意の車線変更の集計 1 行 |
| `<名前>__arbitration.csv` | `edf`・`none` のとき | 調停 1 周期（Tc）ごとの計算時間（`ArbitrationTiming`）。列は時刻・車両数・要求数・割当数と，状態の取りまとめ（`build_us`）・鍵の計算と並べ替え（`keys_us`，Phase A）・割当（`assign_us`，Phase B）・鍵と割当の合計（`arbitration_us`）のマイクロ秒 |
| `<名前>__arbitration_summary.csv` | `edf`・`none` のとき | 上の run の要約 1 行: 測った機械の CPU，周期数，`arbitration_us` の平均・p99（最近傍順位）・最大，`build_us` の平均，要求数の平均と最大，車両数の最大。`aggregate.py` が `summary_long.csv` の `arb_*` 列に写す |
| `<名前>__obstacle_summary.csv` | `--obstacle` を指定したとき | 障害物の計測の要約 1 行 |
| `<名前>__obstacle_avoidance.csv` | `--obstacle` を指定し，該当があるとき | 回避操作を付与された車が障害物のレーンを離れた位置 |
| `<名前>__obstacle_passages.csv` | `--obstacle` を指定し，該当があるとき | 障害物の出現後の退出台数の時系列 |
| 速度ログ（任意のパス） | 環境変数 `V2_SPEED_LOG=<パス>` があるとき | 全車・毎 step の速度指令（`off`・`off-late` では見出し行だけ） |

調停の計算時間は壁時計（`time.perf_counter_ns`）で測るので，機械と負荷（同時に回している run の数など）で変わる。golden の比較からは外している（`tests/golden/run_golden.py`）。

現実性の検査（01），緊急制動の回数，採用した規則の数え上げはファイルに書かず，終了時の表示だけで出す。

### 結果の CSV（`<名前>.csv`）

見出しは `SimulationStatistics._create_csv_with_headers`，値は `add_result` が書く。v1 と同じ列に，v2 だけ締切達成の列を足している（`track_deadline_achievement=True`）。

| 列 | v2 での値 |
|---|---|
| `simulation_time`・`seed` | T（ドレーンを含まない）と seed |
| `inflow_pass`・`inflow_exit` | through・必須 LC のグループの流入量 [veh/h]（グループごとの値を整数にして足したもの） |
| `total_generated_vehicles`・`total_departed_vehicles` | 投入した台数・発進した台数 |
| `running_vehicles`・`exited_vehicles` | 終了時に走行中の台数・退出した台数 |
| `canceled_vehicles` | 流入時刻になっても発進できなかった台数（衝突に関わった車を除く） |
| `traffic volume` | 発進した台数 × 3600 / T（ドレーンの時間は含めない） |
| `average_travel_time` | 退出した車の走行時間（到着 − 発進）の平均 |
| `average_speed` | 車ごとの平均速度（`speed_history` の平均）の，車についての平均。対象は退出した車と終了時に走行中の車 |
| `min_TTC`・`TET` | 最小の TTC（一度も計算しなければ `inf`）と，TTC が `TTC_THRESHOLD`（2.0 s）未満だった車・step の数 × 0.1 s |
| `total_collisions`・`total_vehicles_involved` | 衝突の件数と，各件の関与台数の和 |
| `mandatory_lc_total`・`mandatory_lc_completed`・`mandatory_lc_collided`・`mandatory_lc_incomplete`・`deadline_achievement_rate` | 通常の操作の要求数・完了数・衝突・未完了・達成率 |
| `avoidance_lc_total`・`avoidance_lc_completed`・`avoidance_lc_collided`・`avoidance_lc_incomplete`・`avoidance_achievement_rate` | 回避操作の同じもの |
| `r_pass_*`・`r_exit_*`・`average_r_pass_*`・`average_r_exit_*`・`overtaking_count`・`overtaking_vehicle_count`・`fairness_index`・`max_tail_position` | v2 では使わない（0 か空） |

### 要求個票（`__requests.csv`，`V2CAV.mandatory_request_rows`）

列は `V2CAV.MANDATORY_REQUEST_FIELDS`：`veh_id`・`env`・`phase`（`exit` = 退出時，`end` = 終了時に走行中）・`route`・`target_lane`・`deadline_pos`・`activation_time`・`activation_pos`・`completion_time`・`completion_pos`・`completed_in_time`・`collided`・`final_lane`・`final_lane_pos`（最後に観測したレーンと縦位置）。未完了の操作は `completion_*` が空になる。完了したのに完了の時刻か位置が無い操作があれば `ValueError` を投げる。行のキーが列と合わなければ書き出しで例外になる。

### 失敗個票（`__failures.csv`，`V2CAV.mandatory_failure_rows`）

分類は `COLLIDED`（衝突に関与）→ `TIMEOUT_STUCK`（終了時に走行中で未完了）→ `EXITED_INCOMPLETE`（未完了のまま退出）の順に当てる。列は `veh_id`・`env`・`classification`・`phase`・`route`・`is_avoidance`・`target_lane`・`deadline_pos`・`activation_time`・`activation_pos`・`completed_in_time_raw`（完了したか。衝突に関わった車は完了した操作も載る）・`collided`・`final_road`・`final_lane`・`final_lane_pos`・`final_speed`。

### 任意の車線変更の集計（`__discretionary.csv`，`DiscretionaryCounts.summary_row`）

| 列 | 中身 |
|---|---|
| `discretionary_lane_changes` | `Discretionary.execute` が行った任意の車線変更の数 |
| `blocked_provider` | 譲っている提供車（`CarStatus.YIELDING`）であることで止めた車・step の数 |
| `blocked_requester_clearance` | 移る先の車線を次の目標にしている要求車の前後 `DLC_REQUESTER_CLEARANCE`（50 m）以内であることで止めた数（車・step・候補の車線ごと） |

止めた数に入るのは，速度利得・待ち時間・行き先までの車線変更の数・挿入判定（同じ step の確定との車間を含む）を満たしていた場合だけである。必須の操作を持つ車が任意の車線変更をしないことは，止めた数に入れない（条件の中身は 04）。

### 障害物の計測（`ObstacleMetrics`）

挙動は変えない（traci を呼ばず，毎 step の観測と `speed_history` から計算する）。集計の窓は障害物の出現時刻 `appear_time` から終了時刻まで。しきい値は `obstacle_metrics.py` の定数。

`__obstacle_summary.csv` の列：

| 列 | 中身 |
|---|---|
| `placed_pos`・`placed_time` | 障害物が停車し終えた位置と時刻 |
| `window_start_s`・`window_end_s` | 窓の始まり（`appear_time`）と終わり（終了時刻） |
| `passages_post`・`throughput_post_vph` | 窓の中に退出した車（障害物を除く）の数と，それを窓の長さで割った 1 時間あたりの台数 |
| `avg_speed_post_ms` | 窓の中の速度の標本の平均（退出した車と終了時に走行中の車。障害物を除く） |
| `max_queue_m` | 障害物のレーンで，障害物から後ろへ連なる停止車（速度 `QUEUE_SPEED_EPS`（1.0 m/s）未満，前の停止車との縦位置の差 `QUEUE_CHAIN_GAP_M`（15 m）以下）の列の長さ（障害物の位置から最後尾の停止車の縦位置〔前端〕まで）の，毎 step の最大 |
| `hard_brake_events` | 窓の中で 1 step の速度の低下が `|HARD_BRAKE_DECEL|`（3.0 m/s²）× 0.1 s 以上だった車・step の数（障害物を除く） |
| `avoid_requests` | 回避操作を付与された車の数（本線 edge で観測した分） |
| `avoid_lane_left` | そのうち，障害物より手前で障害物のレーンを離れた車の数 |
| `avoid_stuck_at_end` | 終了時に走行中で，回避操作が済んでいない車の数 |

- `__obstacle_avoidance.csv`：`veh_id`・`remaining_to_obstacle_m`（障害物のレーンを初めて離れた step の，障害物までの残りの距離）。
- `__obstacle_passages.csv`：`bin_start_s`・`arrivals`（窓の中の退出を `PASSAGE_BIN_S`（30 s）ごとに数えたもの。退出の無いビンは行が無い）。

### 速度ログ（`SpeedLog`）

環境変数 `V2_SPEED_LOG=<パス>` のときだけ，そのパスに CSV を書く。`edf`・`none` では，毎 step `apply_speed_command` のあとに走行中の全車について 1 行ずつ書く。

| 列 | 中身 |
|---|---|
| `time`・`veh` | 時刻・車 ID |
| `road`・`lane`・`lane_pos` | edge・レーン番号・縦位置（レーン番号と縦位置は edge ごとに数え直す） |
| `speed` | 観測した速度 |
| `next_speed` | 指令した次 step の速度 |
| `rule`・`target` | 採用した候補の規則名と目標速度（05） |
| `status` | 役割（`RSU.apply_roles` が付ける `NORMAL`・`YIELDING`・`LANE_CHANGING`） |
| `yield_for` | 提供車が譲りの相手として持っている要求車の ID（`V2CAV.yield_for`） |

候補が無かった step は `rule` が空になり，`target`・`next_speed` は前の値が残る。停止を固定した障害物は `rule`・`target`・`next_speed` とも更新されない。

## 終了時の表示（標準出力）

順に次を表示する。

- 台数：投入・走行中・退出・発進・交通量・canceled（この表示の canceled は衝突に関わった車を含む）
- `Phase A`：鍵に同点が出た調停の回数（`RSU.keys_unique`）
- `Phase B`：同じ提供車が二重に割り当てられた調停の回数（`RSU.providers_unique`。`none` では起こりうる）
- `Layer2`：`Layer2.execute_pairs` が行った車線変更の総数（任意の車線変更は含まない）
- `Feasibility`：重なり・すり抜け・往復（`LC_REVERSAL_WINDOW` 以内に元の車線へ戻った）の数（01）
- `Discretionary`：任意の車線変更の数と，止めた数（`__discretionary.csv` と同じ値）
- `Arbitration time`：調停の計算時間の要約（`ArbitrationTiming.summary_line`。`edf`・`none` のとき）
- `Speed: emergency brake events`：`control_speed` が緊急制動の条件に当たって規則 `emergency` の候補を出した車・step の数（`V2CAV.emergency_brake_counter`）の，退出した車と終了時に走行中の車についての合計。その候補が採用されたかは問わない
- `Speed: rule counts`：`apply_speed_command` が採用した規則ごとの車・step の数。規則名は 05 の候補の名前（`limit`・`follow`・`critical`・`emergency`・`stopping`・`yield`・`align`・`hold`・`order`）と，候補が無かった `none`，停止を固定した障害物の `obstacle`
- `Deadline`：通常の操作の完了数 / 要求数（達成率）。障害物を指定したときは回避操作も
- 衝突の一覧

実行中は，区間長と要求を出し始める位置（開始時），グループ別の流入時刻，10 s ごとの時刻，50 s ごとの調停の結果（`RSU.log_assignments`），障害物の減速開始と停車，流入の締切で取り除いた台数，衝突の検出も表示する。

## そのほか

- 衝突：`_check_collision` が毎 step `getCollidingVehiclesIDList` を見て記録する。時刻は今の時刻 − 0.1 s とし，同じ組が 1 s 以内に続けて出たら 1 件にまとめる。
- TTC：走行中の各車について，先行車がいれば `leader_distance`（`getLeader` の車間。探索距離は `LEADER_LOOKAHEAD`（200 m）以上）・先行車の速度・自車の速度から `SimulationStatistics.calculate_TTC` で計算する。自車の方が速いときだけ計算する。
- 走行時間は退出した車だけ，平均速度は退出した車と終了時に走行中の車について計算する。`speed_history` は発進から毎 step の観測なので，本線 edge の外（区間の手前・ランプ・区間の後ろ）の速度も含む。
- canceled：ある step でネット上にいなかった車（そのあと発進した車は外す）。流入時刻になっても発進できなかった車と，流入の締切で取り除いた挿入待ちの車（01）がここに残る。結果の CSV では，衝突に関わった車を除いた台数を書く。
